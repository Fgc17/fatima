## How to validate

First, specify a `model` key in your `fatima.json` file. Models define how Fatima parses and validates loaded values.

If you do not have `fatima.json` yet, run:

```bash
fatima init
```

Afterwards, run:

```bash
npx fatima@latest validate
```

## Validation without setup

It is currently not possible to validate secrets without configuration. Add a `model` object to `fatima.json` and run `fatima validate`.
