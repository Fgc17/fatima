## fatima.json

Fatima uses `fatima.json` as its only project configuration file. It is JSON on purpose: Fatima is a project secret tool, not a JavaScript-only library.

Create it with `fatima init`:

```bash
fatima init
```

Or create `fatima.json` manually in the root of your project:

```json
{
  "$schema": "https://unpkg.com/fatima/schema/fatima.schema.json",
  "generator": "typescript",
  "environment": "{env:NODE_ENV} ?? 'development'",
  "providers": {
    "development": [
      { "provider": "local", "file": ".env" },
      { "provider": "infisical", "environment": "development" }
    ]
  },
  "model": {
    "DATABASE_URL": "url",
    "NODE_ENV": { "type": "string", "args": { "values": ["development", "production"] } }
  }
}
```

The `model` key is optional, but it allows Fatima to parse loaded values and augment generated types.
