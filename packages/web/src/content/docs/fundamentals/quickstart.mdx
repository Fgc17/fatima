## Init CLI

Fatima requires `fatima.json`. Start by installing Fatima and running the init command in your project root.

<CodeTabs groupId="package-manager">
  <CodeTab label="pnpm">

```bash
pnpm add -D fatima
pnpm fatima init
```

  </CodeTab>
  <CodeTab label="npm">

```bash
npm install -D fatima
npx fatima init
```

  </CodeTab>
  <CodeTab label="yarn">

```bash
yarn add -D fatima
yarn fatima init
```

  </CodeTab>
</CodeTabs>

## Configuration

`fatima init` creates `fatima.json`. Fatima will ask you to run `fatima init` if this file is missing.

```json title="fatima.json"
{
  "generator": "typescript",
  "environment": "{env:NODE_ENV} ?? 'development'",
  "providers": {
    "development": [{ "provider": "local", "file": ".env" }]
  },
  "model": {
    "PORT": "integer",
    "NODE_ENV": { "type": "string", "args": { "values": ["development"] } }
  }
}
```

## Create a .env file

Create a `.env` file in the root of your project:

```txt
PORT=3000
NODE_ENV=development
TZ=UTC
NEXT_PUBLIC_URL=http://localhost:3000
```

## Generate types

This will produce a `env.ts` file based on the variables in your `.env` file, with the correct types.

```bash
pnpm fatima generate
```

### Path Alias

Make sure you can import `env` from anywhere in your project without big relative imports.

<CodeTabs groupId="languages">
  <CodeTab label="typescript">

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "env": ["./env.ts"]
    }
  }
}
```

  </CodeTab>
  <CodeTab label="javascript">

```json title="package.json"
{
  "imports": {
    "#env": "./env.js"
  }
}
```

```json title="jsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "#env": ["./env.js"]
    }
  }
}
```

  </CodeTab>
</CodeTabs>

### Go on and use it

```ts
import { env } from "env";
import { Response } from "server";

export async function GET() {
	const port = env.PORT;

	return Response(port);
}
```
