---
title: fatima vault
description: Open the interactive Vault UI.
order: 5
---

```bash
fatima vault
```

The Vault UI manages the local encrypted store. Use it to:

- initialize or unlock the Vault;
- add, edit, and delete secrets;
- import `.env` files;
- create, rename, and delete environments;
- generate user keys;
- rotate the Vault password;
- switch between environment view and matrix view.

Common keys in the command palette include:

| Key | Action |
| --- | --- |
| `a` | Add secret. |
| `e` | Edit selected secret. |
| `d` | Delete selected secret. |
| `r` | Reveal or hide values. |
| `v` | Toggle matrix view. |
| `i` | Import `.env` file. |
| `k` | Generate user key. |
| `p` | Rotate password. |
| `q` | Quit. |
