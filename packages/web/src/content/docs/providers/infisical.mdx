## Configuring the provider

```json
{
  "providers": {
    "development": [
      { "provider": "local", "file": ".env" },
      {
        "provider": "infisical",
        "clientId": "{env:INFISICAL_CLIENT_ID}",
        "clientSecret": "{env:INFISICAL_CLIENT_SECRET}",
        "projectId": "{env:INFISICAL_PROJECT_ID}",
        "environment": "development"
      }
    ]
  }
}
```
